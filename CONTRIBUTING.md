# Katkıda bulunma

Hata veya araştırma önerisi için yeniden üretim adımlarını, kullanılan sürümleri ve
beklenen/gerçek davranışı içeren bir issue açın. Gerçek finansal müşteri verisi,
anahtar, parola veya lisansı belirsiz dosya paylaşmayın.

Kararlı dal `main`, geliştirme dalı `develop`; düzeltme ve özellikler `feature/kisa-konu`
dalında hazırlanır. Var olan katkıları veya Git geçmişini silmeyin; force push kullanmayın.

Kurulum için README'yi izleyin. Python lint, kademeli mypy ve pytest; frontend için
`npm run lint`, `npm run typecheck`, `npm test`, `npm run build` çalıştırın. Tarayıcı
testleri izole sentetik çalışma alanında yapılabilir. Hangi testi çalıştıramadığınızı belirtin.

Pull request açıklamasında sorunu, değişikliği, doğrulama sonucunu ve matematiksel/veri
kapsamı etkisini yazın. Finansal yön, birim, eksik veri veya algoritma anlamını değiştiren
katkılarda bağımsız küçük örneklerle doğruluk gösterin. README ve kullanıcı belgelerini
Türkçe tutun; kaynak eser adlarını değiştirmeyin. Sayısal sonuç üretmeden deney yapılmış
gibi tablo veya grafik eklemeyin.

Yazar ve katkı bilgileri ekip onayıyla kaydedilir. Proje kullanıcı onayıyla MIT
lisanslıdır; katkılarda bu lisansı ve üçüncü taraf kaynakların yükümlülüklerini koruyun.
